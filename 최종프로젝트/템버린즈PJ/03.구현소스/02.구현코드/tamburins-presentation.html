💡 프로젝트 개요

프로젝트명

탬버린즈(Tamburins) 공식 웹사이트 리디자인

제작 목적

탬버린즈는 '규정되지 않은 아름다움을 탐구하는 향수 브랜드'라는 명확한 정체성을 가지고 있습니다. 본 프로젝트는 기존 웹사이트의 사용자 경험(UX)을 개선하고, 브랜드의 독창적인 예술적 감성과 스토리를 온라인 공간에서 더욱 일관되고 몰입감 있게 전달하는 것을 목표로 합니다.

제작 기간 / 팀 구성

제작 기간: 2025.09.01 ~ 2025.10.20 (약 7주)
팀 구성: 개인 프로젝트
역할: UI/UX 설계, 디자인, 웹 퍼블리싱 (HTML, CSS, JavaScript)

🔍 분석 단계 (벤치마킹 & UI 요구사항)

벤치마킹 사이트 분석

국내 프래그런스 시장에서 탬버린즈와 함께 주목받는 '논픽션(Nonfiction)'을 주요 벤치마킹 대상으로 선정하여 UI/UX 및 디자인 전략을 비교 분석했습니다.

탬버린즈 (Tamburins)

  • 장점: 파격적이고 예술적인 비주얼, 감각적 스토리텔링
  • 단점: 예술성에 치중하여 정보 탐색의 직관성이 다소 떨어질 수 있음

논픽션 (Nonfiction)

  • 장점: 간결하고 정제된 레이아웃, 높은 가독성과 직관적인 동선
  • 단점: 시각적 임팩트나 실험적인 요소는 적은 편

결론

탬버린즈의 예술적 정체성을 유지하면서도, 논픽션의 장점인 직관적인 정보 구조와 사용자 편의성을 결합하여 '감각적이면서도 사용하기 쉬운' 웹사이트를 구현하는 방향으로 전략을 수립했습니다.

🧭 피그마 프로토타이핑

핵심 페이지 플로우

사용자가 웹사이트에 방문하여 제품을 구매하기까지의 핵심적인 여정을 시나리오로 구성했습니다.

  • 1. 메인 페이지: 'SUNSHINE' 컬렉션 배너 클릭
  • 2. 제품 목록 페이지: '퍼퓸 선샤인 50mL' 제품 선택
  • 3. 제품 상세 페이지: 제품 정보 확인 후 '장바구니 담기' 클릭
  • 4. 장바구니: 주문 정보 확인 후 '결제하기'로 이동

주요 인터랙션

  • 메뉴 호버(Hover) 시 서브메뉴 드롭다운

💻 HTML 마크업

시맨틱 태그 구조 설계

콘텐츠의 의미와 구조를 명확하게 전달하기 위해 HTML5 시맨틱 태그를 적극적으로 활용했습니다.

  • <header> : 페이지 상단 영역
  • <nav> : 주요 메뉴 링크
  • <main> : 핵심 콘텐츠
  • <section> : 콘텐츠 그룹
  • <article> : 독립적 콘텐츠
  • <footer> : 하단 정보

웹 접근성 준수

  • 모든 이미지에 의미 있는 alt 속성 제공
  • <h1> ~ <h6> 태그로 콘텐츠 위계질서 명확화
  • WAI-ARIA 속성 활용하여 동적 UI 접근성 보강

BEM 방법론 적용

CSS 클래스 이름을 체계적으로 작성하여 코드의 재사용성과 유지보수를 용이하게 했습니다.

예: .product-card__image--sold-out

📱 반응형 웹 구현

디바이스별 Breakpoint 설계

다양한 디바이스 환경에서 최적의 사용자 경험을 제공하기 위해 3개의 브레이크포인트를 설정했습니다.

Mobile

  • ~ 767px
  • 1-2단 레이아웃
  • 햄버거 메뉴

Tablet

  • 768px ~ 1023px
  • 콘텐츠 폭 조정
  • 그리드 컬럼 수 조정

PC (Desktop)

  • 1024px ~
  • 다단 그리드 레이아웃
  • 전체 네비게이션 노출

주요 해상도별 변화

  • PC: 넓은 화면 활용, 4단 그리드
  • Tablet: 3단 그리드, 콘텐츠 폭 조정
  • Mobile: 1-2단 레이아웃, 햄버거 메뉴 전환

  • 터치 슬라이드 기능
  • 모바일 최적화

AOS (Animate On Scroll)

  • 스크롤 애니메이션
  • 간편한 적용

순수 JS와 jQuery의 역할 분담

  • jQuery: 복잡한 DOM 탐색, 검증된 플러그인 활용

하이브리드 전략으로 개발 효율성과 성능을 동시에 확보했습니다.

프로젝트 회고

배운 점: 브랜드의 철학을 웹사이트에 시각적으로, 그리고 기능적으로 녹여내는 과정을 통해 '브랜드 경험 디자인'의 중요성을 깊이 이해하게 되었습니다.

어려웠던 점: 탬버린즈 특유의 비정형적이고 예술적인 레이아웃을 웹 표준을 지키면서 반응형으로 구현하는 과정이 가장 큰 도전이었습니다.

성장 포인트: 단순히 디자인 시안을 코드로 옮기는 퍼블리셔를 넘어, 사용자 경험과 브랜드 가치를 함께 고민하는 웹 개발자로 성장할 수 있는 계기가 되었습니다.
